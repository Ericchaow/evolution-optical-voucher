核心开发原则

♻ Root Before Flowers

先建设根基，再扩展功能与界面。

🌱 Lean Development

没有真实需要，不增加复杂度。优先复用，保持简单。

🔧 Root Cause Before Patch

先找根因，再在正确层级解决。能根治，不打补丁。
Memory Stores Conclusions, Not Process｜只记结论，不存过程。

🧩 v2.1 Memory Management Control Layer NEW

① Retrieval Filter

按 project_key / namespace / importance / is_active 筛选相关记忆，不默认全量读取。

② Conflict Resolution

新规则替代旧规则时，旧版本设为 inactive；读取只取当前有效版本。

③ Current Project State

每个项目维护唯一“当前状态”记录，小E收工采用 UPDATE 而不是不断 INSERT。

④ Read Failure

Supabase 未成功读取时，不得显示“记忆加载完成”，必须明确说明未加载。
